# Экран «Моя колода» — визуальный бриф для редизайна

> Передать Claude Design / любому дизайнеру вместе с парой скриншотов
> текущего состояния. Это описание ТОЛЬКО функциональности и текущего
> визуала — без технических деталей кода. Цель: получить новый дизайн,
> сохранив всё поведение.

## Зачем этот экран

Это «универсальный поиск + библиотека слов». Сейчас он совмещает три задачи:
1. **Колода пользователя** — слова, которые он уже сохранил для повторения по SRS.
2. **HSK-каталог** — академический список из 6 300 слов по уровням HSK 1–6.
3. **Полный словарь Mandarin** — ~125 000 записей из CC-CEDICT для поиска
   любого слова на свете, включая редкие, имена и сленг.

Пользователь приходит сюда через карточку «Слова» на экране «Учить» и решает
здесь две вещи: повторять уже сохранённое или искать новое чтобы добавить.

## Что есть на экране (сверху вниз)

### 1. Хедер
- Слева: круглая кнопка-стрелка «Назад» (возвращает на экран «Учить»).
- По центру: заголовок страницы — сейчас просто «Моя колода» (не отражает
  что внутри ищется ВСЁ, а не только колода — текст устарел).
- Справа: круглая красная кнопка «+» (диаметр ~40 px), ведёт на форму
  ручного добавления слова.

### 2. Поисковая строка
- Светлая «таблетка» во всю ширину, скруглённые углы.
- Слева — маленькая иконка лупы (серая).
- Плейсхолдер меняется в зависимости от режима поиска:
  - В «Сохранённые»: «Поиск hanzi, pinyin, значения».
  - В «Везде / HSK / По теме»: «Ищите везде».
- Вводить можно на любом языке: китайскими иероглифами, пиньинем (с тонами
  или без), английским, русским — система понимает.

### 3. Чипы выбора области поиска (главные)
Горизонтальная скроллируемая строка из 4 пилюль-«чипов». Активный — красный
с белым текстом. Неактивные — белые с серой обводкой и серым текстом.

| Чип | Что значит | Что внутри ищется |
|---|---|---|
| **Везде** | Полный словарь (по-умолчанию) | Колода + 125 000 слов CC-CEDICT |
| **Сохранённые** | Только моя колода | Только то, что я уже добавил |
| **HSK** | Учебный каталог | 6 300 слов HSK 1–6 |
| **По теме** | Тематические подборки | Слова из выбранной темы (еда, путешествия, бизнес и т.д.) |

### 4. Вторичная строка (контекстная)
Появляется ТОЛЬКО в двух режимах:

- **Когда «Сохранённые»** — фильтр по статусу запоминания:
  «Все · К сроку · В процессе · Освоено». Эти чипы такого же стиля как
  главные, но это второй ряд.

- **Когда «По теме»** — горизонтальная лента темат-чипов с названиями
  тем («Еда», «Путешествия», «Бизнес» …). Пока тема не выбрана — экран
  показывает подсказку «Выберите тему» вместо результатов.

### 5. Баннер «переведено как…»
Появляется в режиме «Везде», когда пользователь ввёл слово не на китайском
и система автоматически перевела его на английский, чтобы найти подходящие
hanzi. Светло-розовая плашка с маленькой иконкой искры и текстом
«Ищем как «hello»» (или другим переведённым словом).

### 6. Лента результатов
Вертикальный скролл карточек-строк. У каждой строки три варианта внешнего
вида (зависит от источника):

#### 6.1 Строка сохранённого слова
- Слева: иероглиф большим жирным шрифтом, под ним пиньинь.
- Справа от иероглифа: значение слова на языке пользователя.
- Бейджи под значением: «В колоде» (зелёный), «HSK 1» (розовый), и либо
  «к сроку» (жёлтый), либо «N обзоров» (серый).
- Крайний правый край: иконка-урна (выход красным при тапе) — удалить
  слово из колоды.

#### 6.2 Строка слова из HSK-каталога
- Та же структура: иероглиф + пиньинь + значение.
- Бейдж только «HSK N» (если не сохранено) или «HSK N» + «В колоде» (если
  уже добавлено).
- Крайний правый: круглая иконка-закладка. Красная если можно сохранить
  (BookmarkPlus), зелёная с галочкой если уже сохранено (BookmarkCheck).

#### 6.3 Строка из общего словаря (CC-CEDICT)
- Та же структура: иероглиф + пиньинь + значение.
- Под значением — превью первых двух значений через «·» (у одного слова
  обычно 2–5 значений; полный список в детальном экране).
- Бейджи: «HSK N» если слово в HSK, «В колоде» если сохранено, и
  фиолетовый бейдж **«AI»** на покрытие AI-фоллбэка (когда CC-CEDICT не
  нашёл и подключилась OpenAI).
- Крайний правый: та же закладка.

### 7. Состояния пустоты / загрузки

- **Загружается каталог** (первый вход в HSK или Тему): сообщение
  «Загружаем каталог…».
- **Спиннер «Везде»** во время поиска: маленький крутящийся индикатор +
  подпись «Спрашиваем ИИ…» (если уже задействовался AI-фоллбэк) или
  обычный «Загрузка…».
- **Тема не выбрана**: текст «Выберите тему».
- **Поле пустое в HSK/Везде**: «Введите слово, иероглиф или пиньинь».
- **Ничего не найдено по запросу**: «Ничего не найдено по «X»».
- **Колода пуста + scope=Сохранённые**: «Пока нет слов» + крупная
  кнопка-ссылка «+ Добавьте ваше первое слово».

## Что происходит на тап по слову

Открывается **bottom-sheet** (выезжает снизу, занимает примерно 2/3 экрана):

- Сверху: иероглиф очень крупно (~36 pt), цвета по тонам пиньиня.
- Под ним: пиньинь с тоновыми знаками и индикаторами тонов цветами.
- Под пиньинем: иконка-громкоговоритель — играет произношение через TTS,
  играется автоматически при открытии.
- Бейджи: «HSK N», иногда «POS» (verb / noun / adjective).
- Раздел «Значения»: буллет-лист всех переводов на язык пользователя.
- Раздел «Контекст» (только для сохранённых): предложение, в котором
  слово было встречено, с подсветкой самого слова.
- Кнопки внизу:
  - Если не сохранено — кнопка «Сохранить» (красная).
  - Если сохранено — кнопка «Удалить» (с подтверждением).
  - «Перевернуть карточку» — крутит верхнюю часть, прячет значение,
    показывает только hanzi, чтобы можно было самотестироваться.
- Карточка имеет 3D-эффект переворота на оси Y.

## Микро-взаимодействия и поведение

- Поиск с **debounce 280 мс** — пользователь печатает, запросы летят не
  на каждое нажатие.
- При переключении области поиска (Везде → HSK → Тема): результаты
  сбрасываются, поисковая строка остаётся.
- При вводе слова на русском/английском в режиме «Везде»: сначала
  локальный поиск, если 0 матчей — Google Translate переводит запрос в
  английский → второй проход, в результате внизу появляется баннер
  «Ищем как «X»».
- Если CC-CEDICT всё равно ничего не нашёл и запрос ≥2 символов — крутящийся
  индикатор с подписью «Спрашиваем ИИ…» (полсекунды-секунда), и потом в
  ленте появляется ОДНА результат-строка с бейджем «AI».
- Тап на иконку-закладку у несохранённого слова — мгновенно добавляет в
  колоду, показывает тоаст «Добавлено 你好».
- Тап на иконку-урну — мгновенное удаление (без подтверждения сейчас, это
  baseline UX, можно изменить дизайнером).

## Чего НЕЛЬЗЯ менять (продуктовая логика)

1. **Четыре scope-режима** (Везде / Сохранённые / HSK / Тема) — это
   архитектурно зашитый разрез данных. Можно красиво переоформить
   переключатель, но удалять режимы нельзя.
2. **Один поисковый инпут на все режимы** — пользователь не должен
   перепечатывать запрос при переключении режима.
3. **Состояние «AI-фоллбэк»** — должно визуально отличаться от обычной
   карточки, чтобы пользователь знал «это от ИИ, не CC-CEDICT».
4. **Состояние «уже в колоде»** должно быть мгновенно очевидно — иконка
   меняется со «закладка-плюс» на «закладка-галочка-зелёная».
5. **Bottom-sheet с деталями** остаётся, переворот карточки тоже —
   это центральная фича для самопроверки.

---

## Жесты / нюансы (для полноты)

- Скролл ленты — обычный вертикальный, без свайпов для удаления (хотя
  это можно добавить как UX-улучшение).
- Bottom-sheet закрывается потянув вниз или тапом на оверлей.
- Иконка-закладка в строке списка реагирует на тап с лёгким haptic-фидбеком.
- Возврат с этого экрана — круглая стрелка слева сверху, всегда ведёт
  на «Учить» (не на главную и не «назад» в браузерном смысле — там бывали
  баги с Tabs).

## Контекст в приложении

- Экран ОТКРЫВАЕТСЯ из карточки «Слова» (左верхняя в сетке РАЗДЕЛЫ на
  экране «Учить»). На той же сетке есть «HSK каталог», «Иероглифы»,
  «Грамматика». «Слова» — самый частый вход.
- Дизайн приложения — paper-белый фон, акцентный красный (#E63946),
  тёмно-бордовые «постер»-карточки (как hero на главной), шрифт системный
  для UI и Noto Serif SC / PingFang SC для китайского.
- Стиль вообще — минималистичный с китайским каллиграфическим акцентом
  (большие водяные знаки-иероглифы на «постер»-карточках).

Этот экран сейчас довольно «технически-минималистский» — гладкие пилюли,
сухие бейджи, никаких иллюстраций. У дизайнера большое пространство
сделать его теплее, информативнее, и более стилево связанным с
«постер»-эстетикой Home / Learn.
