# Раздел «Иероглифы» — визуальный бриф для редизайна

> Передать Claude Design / любому дизайнеру вместе со скриншотами текущего
> состояния. Это описание ТОЛЬКО функциональности и текущего визуала —
> без технических деталей кода. Цель: получить новый дизайн, сохранив всё
> поведение. Дизайнер сам решает раскладку, иерархию, какие шаги объединить
> или разнести, как сделать сетку «дорожной карты» более выразительной,
> как добавить геймификацию.

---

## Зачем этот раздел

Это **«дорожная карта» по 6 уровням HSK + пошаговый тренажёр каждого
иероглифа в одиночку**. Если «Слова» — про лексику, а «Грамматика» —
про конструкции, то «Иероглифы» — про **глифы как таковые**: знакомство,
распознавание, произношение, написание (порядок черт), активное
воспроизведение.

Пользователь приходит сюда с экрана «Учить» и решает:
1. На каком HSK-уровне он сейчас работает (HSK 1 / 2 / 3 / 4 / 5 / 6).
2. Какой иероглиф из этого уровня прокачать — открывает карточку.
3. Внутри карточки проходит **5 шагов**, после которых иероглиф считается
   «освоенным» (mastered).
4. Возвращается к карте и видит, что прогресс сохранился (статус сменился
   на «выучено», граница карточки позеленела).

Каждый иероглиф имеет статус: «новый» (никогда не открывал) / «в процессе»
(сделал ≥1 шаг, но ещё не дошёл до конца) / «освоен» (5/5).

---

## Текущая архитектура раздела (2 экрана)

```
character/
├── index.tsx       ← Дорожная карта: сетка иероглифов по HSK + фильтры
└── [hanzi].tsx     ← Карточка одного иероглифа со всеми 5 шагами обучения
```

Карточка `[hanzi].tsx` — **единый экран с переключаемым контентом**: один
ScrollView, внутри которого рендерится один из 6 подэкранов (`LearnStep`,
`RecognizeStep`, `PronounceStep`, `WriteStub`, `ProduceStep`,
`MasteredView`). Нет отдельных URL для каждого шага — навигация по шагам
происходит внутри состояния этого экрана.

## ЭКРАН 1 — Дорожная карта (`/character`)

### Что есть на экране (сверху вниз)

#### 1. Заголовок
- Текст «Иероглифы HSK» (по умолчанию — может быть локализовано).

#### 2. Карточка-сводка (3 счётчика в ряд)
- Светлая «таблетка» во всю ширину, скруглённые углы.
- Внутри три равных колонки:
  - **Всего** — общее число иероглифов на выбранном HSK уровне (например, 150).
  - **В процессе** — сколько начато но не достроено (жёлтым).
  - **Освоено** — сколько 5/5 (зелёным).
- Каждая колонка: крупное число + caption-подпись под ним.

#### 3. Лента HSK-уровней
- Горизонтальный скролл из 6 круглых «пилюль»: «HSK 1», «HSK 2», …, «HSK 6».
- Активная пилюля — красная с белым текстом, остальные — белые с серой
  обводкой.
- Переключение перерисовывает грид ниже и обновляет счётчики (`Всего`,
  `В процессе`, `Освоено` — пересчитываются под выбранный уровень).

#### 4. Лента статус-фильтров
- Под HSK — второй горизонтальный ряд таких же пилюль: «Все», «Новые»,
  «В процессе», «Освоено».
- Та же логика: активный — красный, остальные — белые.
- Фильтрует видимые карточки в гриде ниже.

#### 5. Грид иероглифов
- 2D-сетка карточек, каждая ~72×92 px:
  - Иероглиф крупно (30 pt) по центру.
  - Под ним мелким серым — пиньинь первого чтения.
  - Если иероглиф уже начат — мелкая подпись «N/5» внизу (где N — номер
    последнего пройденного шага).
- **Цвет рамки** карточки кодирует статус:
  - «новый» — серая.
  - «в процессе» — оранжевая/янтарная.
  - «освоен» — зелёная.
- Фон карточки: белый для «новых», слегка серее для уже начатых.
- Тап → переход на `/character/{hanzi}`.

#### 6. Состояния пустоты / загрузки
- Пока тянется словарь — крутящийся индикатор по центру.
- Если фильтр оставил 0 карточек — текст «Здесь ничего нет» (или подобный)
  по центру.

### Что происходит на тап
- Тап по HSK-пилюле: меняет когорту словаря, грид перерисовывается.
- Тап по статус-фильтру: грид фильтруется без сетевого запроса.
- Тап по карточке иероглифа: открывает 5-шаговую карточку этого иероглифа.

## ЭКРАН 2 — Карточка иероглифа (`/character/[hanzi]`)

Это **сердце раздела**. Один экран, один иероглиф, 5 этапов обучения,
после которых он становится «mastered». Прогресс сохраняется на сервере
после каждого шага — пользователь может выйти и вернуться позже.

### Шкала прогресса вверху
- Под топ-баром — 5 тонких полосок 4 px в ряд.
- Пройденные шаги — зелёные.
- Текущий шаг — красный.
- Будущие шаги — серые.
- Над шкалой — подпись «N / 5 · {название шага}» (например «Шаг 3 / 5 ·
  Произношение»).

### Топ-бар
- Слева ✕ — закрывает карточку, возвращает на сетку.
- В центре две строки:
  - Серый caption: «HSK N» (если уровень известен) или «Иероглиф».
  - Жирная строка: «Шаг X / 5 · Название шага» или «Освоено» если 5/5.
- Справа топ-бар сейчас пуст (в этом месте можно добавить настройки /
  скип-кнопку / TTS-скорость).

### Состояния (фазы) — 5 шагов

#### Шаг 1 — «Изучить» (LearnStep)
Знакомство с иероглифом. Цель — посмотреть-послушать-понять, без оценки.

- Огромный иероглиф 144 pt по центру (это центральный визуальный момент).
- Под ним пиньинь крупно, красный акцент.
- Рядом круглая красная кнопка-таблетка с иконкой 🔊 — играет TTS
  (zh-CN, rate 0.85). Автоматически проигрывается при открытии шага.
- Карточка «ЗНАЧЕНИЯ» — буллет-лист всех переводов на язык пользователя.
- Карточка «МНЕМОНИКА» (красным акцентом, светло-красный фон) — если в
  словаре есть mnemonic-string, показывает её. Это короткое мнемоническое
  пояснение, как запомнить иероглиф (например, «иероглиф 木 — это
  схематическое дерево»).
- Блок «СЛОВА С {char}» — горизонтальный список 6–12 chips со словами,
  которые содержат этот иероглиф (например, для 木 — 木头, 树木, 木匠).
  Каждый chip: hanzi + пиньинь + значение. Тап по chip-у открывает
  bottom-sheet с деталями слова (тот же что в «Словах»).
- Ряд stat-чисел: «Черт», «HSK», «Частота» (frequency rank).
- Большая красная кнопка «Понятно» — переход на шаг 2.

#### Шаг 2 — «Узнать» (RecognizeStep)
Распознавание иероглифа по значению. 4-вариантный multiple choice.

- Caption «Какой иероглиф значит …»
- Большой текст значения (например, «дерево») — 24-30 pt по центру.
- Сетка 2×2 из 4 карточек-вариантов:
  - В каждой большой иероглиф (40 pt).
  - 3 distractors — случайные иероглифы из той же HSK-когорты.
- Тап по карточке:
  - Правильный — зелёная рамка вокруг ответа.
  - Неправильный — красная рамка вокруг выбранного, зелёная вокруг
    верного. Под обоими появляется пиньинь подсказкой.
  - Haptic-фидбек (лёгкий на правильном, тяжёлый на неправильном).
- Появляется большая красная кнопка «Дальше» → шаг 3.

#### Шаг 3 — «Произнести» (PronounceStep)
Произношение иероглифа. Whisper-оценка через edge-функцию.

- Иероглиф 96 pt по центру.
- Под ним пиньинь крупно красный (с диакритикой).
- Круглая 🔊 кнопка — воспроизводит образцовое произношение TTS.
- Большая круглая красная кнопка-микрофон 84×84 (внизу):
  - Тап → начинает запись, кнопка пульсирует, цвет меняется на danger,
    иконка превращается в квадрат-«стоп».
  - Тап ещё раз (или авто-стоп) → отправляет аудио на edge-функцию
    `score-pronunciation`, показывает «Оцениваем…».
  - После оценки: карточка с цветной рамкой — `verdictColor` (excellent/
    good = зелёный, try_again = жёлтый, unclear = красный) + текст
    «Отлично / Хорошо / Попробуй ещё / Неразборчиво» + большое число
    «N%» (score).
  - Если есть transcript — «Услышал: 字» (Whisper трансрипт того, что
    он распознал).
- Ниже кнопка «Дальше» (large red) — переходит на шаг 4. Если score ≥
  60% — `asCorrect=true`, иначе false.
- Текстовая ссылка «Пропустить произношение» — пропускает шаг без оценки.

#### Шаг 4 — «Написать» (WriteStub)
Тренировка порядка черт.

- Большой холст ~280×280 px по центру:
  - По умолчанию — `StrokeQuiz` (интерактивный quiz, пользователь сам
    обводит черты пальцем; компонент проверяет последовательность).
  - Внизу кнопка «Показать анимацию» (ghost) — переключает на
    `StrokeAnimator` (видео-стиль анимация всех черт по порядку).
- Подсказка серым: «Посмотри, как пишется. Когда готов — пройди дальше».
- Большая красная кнопка «Дальше» (текст меняется на «Продолжить» если
  юзер завершил StrokeQuiz).

#### Шаг 5 — «Произвести» (ProduceStep)
Активная продукция: пользователь видит значение → набирает пиньинь →
выбирает иероглиф.

- Caption «Как сказать …»
- Большое значение на языке пользователя по центру.
- **Подфаза 1 — набор пиньиня:**
  - Подпись «Введи пиньинь».
  - TextInput по центру (24 pt текст), плейсхолдер — нормализованный
    пиньинь без тонов (например «mu»).
  - Подсказка серым: «Ожидаем: mù» — оригинал с тонами для глаза.
  - Тоны можно опускать (нормализация снимает диакритику с обеих сторон).
- **Подфаза 2 — выбор иероглифа** (открывается когда пиньинь введён
  правильно):
  - Подпись «Теперь выбери иероглиф».
  - Сетка из 4 карточек-кандидатов 2×2:
    - Целевой иероглиф + 3 distractor'а, желательно с такой же первой
      буквой пиньиня (например, для 木 mù — другие на m: 妈 mā, 满 mǎn,
      面 miàn).
    - Большой иероглиф 40 pt в каждой карточке.
  - Логика выбора как в RecognizeStep: правильный → зелёная рамка,
    неправильный → красная рамка + зелёная на верном.
- Большая красная кнопка «Дальше» — завершает шаг 4, продвигает на «mastered».

#### Шаг 6 — «Освоено» (MasteredView)
Финальный экран после 5-го шага. Показывается также при повторном входе
в карточку освоенного иероглифа.

- Большой зелёный круг 120×120 с белой галочкой ✓ по центру.
- H1 «Молодец!» (или другой поздравительный текст).
- Иероглиф крупно красный (64 pt) ещё раз — как трофей.
- Подсказка серым: «Возвращайся периодически — повторение закрепляет
  результат».
- Большая красная кнопка «К карте» → возврат на грид.

---

## Что происходит между шагами

- Каждый шаг при завершении вызывает `advanceStep(step + 1)` — сервер
  атомарно обновляет `user_characters.step_completed`.
- В таблице активности `daily_activity` обновляются счётчики:
  - `characters_learned += 1` если перешли на шаг 5 (mastered).
  - `xp_earned += 2` за обычный шаг, `+3` если шаг засчитан как
    «правильный» (asCorrect).
- Если пользователь выходит до завершения 5 шагов — следующее открытие
  карточки начнётся с того шага, на котором остановился (через
  `step_completed`).
- Под центральным контентом мелким серым показывается строка:
  «Повторений: N · Следующий показ через X» — текущая SRS-задержка,
  считающаяся от поля `due_at` в базе.

## Что НЕЛЬЗЯ менять (продуктовая логика)

1. **Пять шагов — это «лестница» с растущей сложностью.** Learn → Recognize
   → Pronounce → Write → Produce. Каждый шаг — отдельный когнитивный
   режим (узнать ↔ ввести ↔ сказать ↔ написать). Можно переоформить
   визуально, но удалять шаги или сливать соседние нельзя — они тестируют
   разные навыки.

2. **Mastered = 5/5.** Иероглиф считается выученным только после шага 5,
   не раньше. На карте грид показывает зелёную рамку именно после 5/5.

3. **Возможность пропустить произношение** — оно дорогое (Whisper) и
   зависит от микрофона / разрешений. Должна быть альтернативная
   текстовая кнопка «Пропустить произношение» — без неё пользователи в
   тихих местах застрянут на шаге 3.

4. **Огромный иероглиф в шаге Learn (144 pt)** — это центральная
   визуальная единица раздела. Дизайнер может его переоформить (с
   водяным знаком, с brushstroke-эффектом, с пастельным фоном), но он
   должен оставаться **самым большим элементом на экране**.

5. **Блок «Слова с этим иероглифом»** на шаге Learn — критически важная
   фича для понимания морфологии. Если иероглиф никогда не встречается
   изолированно (например, 们), пользователь должен сразу увидеть,
   что он живёт внутри слов (我们, 你们 и т.д.).

6. **Stroke-quiz и stroke-animator на шаге Write** — это две модальности
   для одного контента. Quiz — активный (пользователь обводит сам),
   animator — пассивный (просто смотрит). Обе должны остаться доступны.

## Жесты / нюансы

- Свайпов между шагами нет — переход только по кнопке «Дальше». Это
  намеренно: каждый шаг требует выполнения активного действия, а не
  пропускания.
- На шаге Recognize нельзя повторно выбрать ответ после первого тапа —
  рамка остаётся показывать правильный/неправильный, чтобы пользователь
  увидел разбор.
- На шаге Pronounce можно записываться несколько раз — после первой
  оценки появляется кнопка «Записать ещё раз» (ghost). Финальное grade
  определяется последней попыткой при тапе «Дальше».
- На шаге Write можно посмотреть анимацию — это считается «отказом от
  активного обведения», но шаг всё равно засчитается. Это компромисс:
  лучше дать пользователю не застрять, даже если он не написал сам.
- На шаге Produce TextInput автофокусится — клавиатура открывается сразу.

## Что сейчас «технически-минималистски» и может быть переосмыслено

Дизайнер сам решает. Список того, что **сейчас в продукте простое и
сухое** — можно сделать богаче, но это не обязательно:

- **Грид-карточки на дорожной карте** — сейчас одинаковые квадратики
  72×92. Можно сделать визуальную иерархию по частотности (более
  частотные крупнее), или по статусу (новые — пастельные, освоенные —
  «золотые медальки»).
- **Прогресс-«пчелиные соты»** — вместо сетки 2D можно сделать
  «карту»-сетку как в Duolingo (узлы по дугам), где порядок изучения
  диктуется частотой использования.
- **Иллюстрации-этимологии** — для базовых иероглифов (山, 水, 火, 木)
  есть классические пиктографические корни. Можно добавить мини-серию
  иллюстраций «как из рисунка стал иероглиф» — это сильнейший
  мнемонический инструмент.
- **Шаг Learn — мнемоника** — сейчас просто красная плашка с текстом.
  Можно добавить визуализацию: вставить иконку/символ рядом с описанием,
  или дать пользователю редактировать свою мнемонику (поле уже есть в
  базе: `mnemonic_user_override`).
- **Шкала прогресса наверху (5 полосок)** — сейчас плоская. Можно сделать
  «змейкой» — каждый шаг визуально соединён со следующим, как уровни в
  игре.
- **Шаг Pronounce — Whisper feedback** — сейчас простой текст «Услышал:
  字». Можно сделать визуальный сравнитель волн / тон-контуров (модное
  решение в Hello Chinese / Pleco).
- **Шаг Write — Stroke quiz** — сейчас белый холст с тонкими линиями.
  Можно стилизовать под «рисовая бумага» (фон с лёгкой текстурой,
  brush-style линии черт), чтобы написание ощущалось как каллиграфия,
  а не как палочки и кружочки.
- **Mastered-экран** — простой круг + галочка. Можно дать конфетти,
  badge достижения «N иероглифов сегодня», золотую штриховку поверх
  иероглифа.
- **Дорожная карта без визуальной мотивации** — нет «следующего
  иероглифа» (рекомендации). Дизайнер может ввести карточку-CTA сверху
  «Следующий: 木 ✦ открыть».
- **Грид без сортировки** — сейчас всегда по `frequency_rank`. Можно
  ввести альтернативный режим сортировки (алфавит pinyin / по статусу
  изучения / по дате последнего обращения).

Эти вещи **не обязательны** к реализации, но указывают на места, где
сейчас визуальная плотность низкая, а функциональная — высокая.

## Контекст в приложении

- Раздел открывается с карточки «Иероглифы» на экране «Учить» (рядом с
  «Слова», «HSK каталог», «Грамматика»).
- Палитра приложения:
  - Бумажный фон `#FAFAF7`, поверхность `#FFFFFF`, тёплая беж-поверхность
    `#F5F1EA`, тёплая граница `#ECE7DE`.
  - Красный акцент `#E63946`, светло-красный «muted» `#FFE2E4`.
  - Статусы: success `#22C55E`, warning `#F59E0B`, danger `#EF4444`.
  - Тоновые цвета пиньиня: `#C8102E` / `#1F8A5B` / `#6A4C9C` / `#3D6FB5` /
    `#8A847C` (1/2/3/4/neutral).
- Шрифты:
  - UI — Inter (500/600/700/800).
  - Китайский — Noto Serif SC (700/900). Иероглифы 144 pt на шаге Learn
    рендерятся именно этим шрифтом — он даёт классический «книжный»
    штрих, не игрушечный sans.
  - Пиньинь — JetBrains Mono (500).
- Эстетика: «бумажный плакат + ink stamp». Большие водяные иероглифы,
  каллиграфический акцент, минимум шума, тёплые сурфейсы.

Этот раздел сейчас один из самых **разнообразных по типам взаимодействий**
(тап + drag для черт + микрофон + клавиатурный ввод). Главная задача
дизайнера — сделать **единый визуальный язык** для всех 5 шагов так,
чтобы переходы между ними не ощущались как «другие экраны», а как
**фазы одной встречи с иероглифом**. И — заставить mastered-экран
ощущаться достижением, а не просто завершением.
