# Раздел «Грамматика — Pattern Sprints» — визуальный бриф для редизайна

> Передать Claude Design / любому дизайнеру вместе со скриншотами текущего
> состояния. Это описание ТОЛЬКО функциональности и текущего визуала —
> без технических деталей кода. Цель: получить новый дизайн, сохранив всё
> поведение. Дизайнер сам решает раскладку, иерархию, какие элементы
> объединить или вынести, что добавить как иллюстрацию или геймификацию.

---

## Зачем этот раздел

Это **тренажёр грамматики на скорость** («Pattern Sprints»). Идея простая:
берём одну грамматическую конструкцию (например, «是…的», или «把-конструкция»,
или «V起来»), и прогоняем её через **десятки фраз с разной лексикой**,
пока производство китайского предложения не становится рефлекторным
(целевая скорость — ~1.5 секунды на фразу).

Пользователь приходит сюда через карточку «Грамматика» на экране «Учить»
и решает здесь:

1. Какой **уровень грамматики** тренировать (HSK 1 / 2 / 3 — это не уровни
   сложности слов, а **наборы грамматических явлений**).
2. С какой **лексикой** (HSK 1, HSK 1–2, …, HSK 1–6 — чем шире, тем
   больше разнообразных примеров для одной и той же конструкции).
3. Какую конкретную **конструкцию** прогнать — либо ткнуть в список,
   либо «случайный спринт» (кубики 🎲 → выбирает случайную из списка).
4. Перейти в **«Мои паттерны»** — личную колоду авторских конструкций,
   которые пользователь создал руками или импортировал JSON-ом.

Раздел тесно связан с «постер-эстетикой» главного экрана и экрана
«Учить» — те же тёмно-бордовые «постер»-карточки с водяным знаком-иероглифом,
красный акцент #E63946, золотая надпись-«eyebrow» #E0B86A.

---

## Текущая архитектура раздела (4 экрана)

```
grammar/
├── index.tsx                     ← Главная раздела: выбор уровня + список конструкций
├── [id].tsx                       ← Тренажёр одной конструкции
└── personal/
    ├── index.tsx                  ← «Мои паттерны» — личная колода
    ├── new.tsx                    ← Форма создания конструкции
    ├── [id].tsx                   ← Редактирование/просмотр своей конструкции
    ├── import.tsx                 ← Импорт колоды JSON
    └── export.tsx                 ← Экспорт колоды JSON
```

Тренажёр **общий** для встроенных и личных конструкций — оба источника
открываются на `[id].tsx`, только встроенные передают `?grammar=N&level=N`,
а личные — `?source=personal`.

## ЭКРАН 1 — Главная раздела (`/grammar`)

### Что есть на экране (сверху вниз)

#### 1. Топ-бар
- Слева: круглая кнопка-стрелка «Назад» (44 × 44, белая с серой обводкой).
  Ведёт всегда на экран «Учить» (не на главную — фикс бага с Tabs).
- Справа: круглая кнопка с иконкой кубиков 🎲 (44 × 44, тоже белая).
  Тап = «случайный спринт» — берёт случайную конструкцию из текущего
  списка и сразу открывает тренажёр.

#### 2. Eyebrow + крупный заголовок + лид-абзац
- Красная «черта» 28×4 + слово «SPRINT-ПАТТЕРНЫ» (12pt, ExtraBold,
  buchstaben-spacing 1.4) + крошечный иероглиф «· 法».
- H1 заголовок: «Грамматика **на скорость**» (36pt, два ряда).
- Лид: «Одна конструкция → десятки фраз с разной лексикой. Чем выше
  скорость — тем ближе автоматическая речь.»

#### 3. Постер-карточка «Мои паттерны»
Тёмно-бордовая (#1F0C10) карточка во всю ширину:
- Фоновый радиальный градиент (бордовый, теплее справа сверху).
- Огромный водяной иероглиф «我» в правом нижнем углу, очень-очень
  прозрачный (rgba 255,80,90,0.1) — постер-эстетика.
- Слева: квадратная плитка 56×56 (#5C1F26) с иконкой пользователя 👤
  красным.
- Eyebrow «МОЯ КОЛЛЕКЦИЯ» золотом (#E0B86A).
- Тайтл «Мои паттерны» белым.
- Подтайтл серым: либо «Создайте свои или импортируйте JSON» (если
  пусто), либо «N конструкций · M фраз».
- Справа — шеврон.

#### 4. Секция «УРОВЕНЬ ГРАММАТИКИ»
- Заголовок-секции: красная вертикальная полоска 4×22 + «УРОВЕНЬ
  ГРАММАТИКИ» (14pt ExtraBold, spacing 1.4) + справа «X / Y конструкций».
- 3 равных карточки в ряд: **HSK 1**, **HSK 2**, **HSK 3**.
  - Неактивная: белая с серой обводкой, eyebrow «HSK» серый, огромная
    цифра «1» черная 44pt, под ней «N / N» (прогресс).
  - Активная: тёмно-бордовый фон, eyebrow золотой, цифра белая, прогресс
    золотом.
  - На карточке «HSK 3» — маленький красный бейдж «NEW» в правом
    верхнем углу.
  - Если уровень полностью пройден — галочка ✓ зелёная рядом с прогрессом.

#### 5. Секция «УРОВЕНЬ ЛЕКСИКИ»
- Тот же заголовок-секции.
- Под ним светлая карточка-объяснение: «Конструкции **HSK 2**. Слова —
  из **HSK 1–3** (≈ 600 слов)».
- Горизонтальная лента «пилюль-чипов» HSK-уровней:
  - Лейбл вверху: «HSK N» (если совпадает с уровнем грамматики) или
    «HSK 1—N» (кумулятивная нотация).
  - Подпись внизу: количество слов (например «1.2k»).
  - Активный — красный фон, белый текст.
  - Неактивные — белый фон, серая обводка.

#### 6. Большая красная кнопка «Случайный sprint · 5 мин»
- Шириной во весь экран, икона кубиков + текст.
- Это **дублирует** круглую 🎲-кнопку из топ-бара, но более «зазывная»
  — это основной CTA.

#### 7. Секция «КОНСТРУКЦИИ»
- Тот же заголовок-секции + справа счётчик «12 паттернов».
- Вертикальный список карточек-строк (одна строка = одна конструкция):
  - Слева: цветная квадратная плитка 52×52 с первым иероглифом
    конструкции внутри. Палитра циклится — красный/синий/зелёный/фиолетовый/янтарный,
    каждый со своим пастельным фоном и насыщенным цветом текста.
  - В центре: имя конструкции по-китайски (17pt Bold), под ним —
    русское название (13pt серый), под ним мелким серым:
    «N фраз  ·  S + 把 + O + V». Последнее — «шаблон» (синтаксическая
    структура).
  - Справа: маленький круглый красный шеврон.

### Что происходит на тап

- Тап на карточку «HSK N»: меняет активный уровень грамматики; список
  конструкций перерисовывается. Сохраняется в storage.
- Тап на чип «HSK 1–N»: меняет уровень лексики; список конструкций тех
  же, но **фразы внутри них** теперь другие (брались из другого набора).
- Тап на постер «Мои паттерны»: открывает экран личной колоды.
- Тап на конструкцию в списке: открывает тренажёр для неё.
- Тап на 🎲 (любую): открывает тренажёр для случайной конструкции из
  текущего списка.

## ЭКРАН 2 — Тренажёр конструкции (`/grammar/[id]`)

Это **сердце** раздела. Один экран, на котором пользователь прокручивает
все фразы для выбранной конструкции одну за другой.

### Состояния (фазы)
1. **prompt** — показан только русский (или другой UI-язык) текст
   фразы. Идёт обратный отсчёт.
2. **revealed** — открыт китайский перевод + пиньинь, кнопка «Озвучить»,
   кнопка «Дальше».
3. **done** — все фразы пройдены, показан итоговый экран.

### Что есть на экране

#### Топ-бар
- Слева — стрелка ← «Назад» (текстовая, не круглая).
- В центре — две строки:
  - Серая мелкая: «Грамм. HSK 2 · лекс. HSK 1–3 · S + 把 + O + V».
    (Для личной — «Моя колода · без шаблона».)
  - H3 по-китайски: имя конструкции «把-конструкция (объект перед глаголом)».
- Справа — иконка-шестерёнка ⚙ (открывает модалку настроек).

#### Подзаголовок
- Русское имя конструкции мелким серым: «Перемещение/перестановка объекта».

#### Прогресс-бар
- Тонкая полоса 6px на всю ширину. Заполнение красным — текущая фраза
  / всего фраз.

#### Карточка «Промпт» (фаза prompt)
- Маленькая шапка «ФРАЗА 3 / 28». Если фраза не на нужном языке —
  справа индикатор «RU» / «EN» / etc.
- Большой текст русской фразы (26pt, lineheight 34, weight 600).

#### Карточка «Reveal-зона»
**В фазе prompt:**
- По центру — круглый таймер 96×96 («countdown ring»):
  - Внутри — цифра оставшихся секунд (h1, акцентом).
  - Цвет рамки меняется: красный (>50%) → жёлтый (>0%) → красный
    (закончилось).
  - Если таймер выключен — вместо цифры иконка глаза 👁.
- Под кругом — подсказка: «Произнесите вслух. Когда готовы — нажмите
  Показать» (или «… Ответ появится автоматически» если auto-reveal).

**В фазе revealed:**
- Карточка с акцентной красной рамкой:
  - Eyebrow «КИТАЙСКИЙ» красным.
  - Справа кнопка-таблетка «🔊 Озвучить» (красная, со звуком TTS,
    воспроизводит фразу по-китайски).
  - В центре — фраза с иероглифами 36pt и пиньинем над/под ними
    (компонент HanziWithPinyin делает посимвольный пиньинь).
- Карточка появляется с анимацией fade + slideUp 200ms.

#### Кнопки внизу (фазы prompt и revealed)
- Слева — «Пропустить» (ghost, серая).
- Справа — основная:
  - В prompt: «Показать» с иконкой 👁.
  - В revealed: «Дальше» с шевроном →.

### Экран DONE (после последней фразы)
- По центру большой зелёный кружок с галочкой ✓ 96×96.
- H1 «Круг закрыт».
- Подпись: «Конструкция «把 bǎ» — 28 фраз отработано.»
- Две статистические карточки в ряд: «Всего времени: 2м 14с» и
  «На фразу: 4.8с».
- Кнопки: «Повторить ещё раз» (primary, с иконкой ↺) и «К списку
  конструкций» (secondary).
- Внизу мелким серым: «Спринт-формат: 5–8 проходов на конструкцию.
  Возвращайтесь и ускоряйтесь — цель ≈ 1.5с на фразу.»

### Модалка настроек тренажёра (тап ⚙)
Bottom-sheet с 4 (или 5 для встроенных) группами настроек, каждая
группа — заголовок + хинт + ряд чип-кнопок (Pill chips, акцент = красный):

1. **Уровень грамматики** (только для встроенных): HSK 1 / HSK 2 / HSK 3.
2. **Уровень лексики** (только для встроенных): HSK 1 / HSK 1–2 / …
   / HSK 1–6.
3. **Таймер на фразу**: «Без таймера» / 2с / 3с / 4с / 5с / 8с.
4. **Режим показа ответа**: «Ручной» / «Авто».
5. **Автопереход к следующей**: «Выкл.» / 2с / 3с / 5с.

Изменение настроек 1–2 ⇒ сбрасывает фразы и начинает заново.

## ЭКРАН 3 — «Мои паттерны» (`/grammar/personal`)

Личная колода авторских конструкций.

### Что есть на экране

#### Топ-бар
- Слева стрелка ←.
- В центре две строки: eyebrow «ЛИЧНАЯ КОЛОДА» + H3 «Мои паттерны».

#### Если колода пуста
- Карточка с заголовком «Колода пуста» и параграфом-объяснением:
  «Создайте свою первую конструкцию или импортируйте JSON. …»

#### Если колода не пуста
- Строка мелким серым: «N конструкций  ·  M фраз».

#### Кнопки управления (ряд)
- Primary «Создать» (с +) — ведёт на форму создания.
- Secondary «Импорт JSON» (с ↓) — экран импорта.
- Под ними, если колода не пуста — ghost «Экспорт JSON» (с ↑).

#### Список конструкций
Карточки в столбик:
- Слева кружок 52×52 с красным фоном (accentMuted) и первым иероглифом
  внутри (или ✎ если иероглифа нет).
- В центре: имя по-китайски (Bold) + русское имя (small) + строка
  «📚 N фраз · шаблон».
- Справа: иконка-урна 🗑 (тап → красная подсветка «Подтвердить?», ещё
  тап в течение 3 секунд → удаляет) + шеврон.

#### Совет внизу
- Серая подпись «СОВЕТ» + параграф: «Создавайте конструкции под свои
  слабые места: например «начал делать (V起来)» с 30 разными глаголами.
  Тренируйтесь по тому же сценарию, что встроенные HSK-паттерны —
  таймер + повторы.»

## ЭКРАН 4 — Создание/редактирование конструкции (`/grammar/personal/new`, `/grammar/personal/[id]`)

> Простая форма, дизайн менее критичен — но желательно стилево
> объединить с остальными экранами.

- Поля: «Имя по-китайски», «Имя по-русски», «Шаблон» (опционально,
  например «S + 把 + O + V»).
- Список фраз: каждая фраза — три поля (RU / ZH / PY). Кнопка «+
  Добавить фразу». Сейчас фразы можно редактировать только по одной.
- Кнопка «Сохранить» / «Удалить конструкцию».

## Что НЕЛЬЗЯ менять (продуктовая логика)

1. **Два дименшна уровня** (грамматика × лексика) — это архитектурно
   важная разделимость: пользователь хочет тренировать «HSK 2 грамматику
   на словах HSK 1+2+3», и эту матрицу нельзя плоско схлопывать в один
   слайдер «уровень».
2. **Фаза prompt с обратным отсчётом — основной паттерн тренажёра**.
   Можно красиво переоформить таймер (анимированная заливка, прогресс-
   арка, что угодно), но идея «секунды на ответ» — ключевая.
3. **Тап «Показать» открывает китайский с пиньинем** — это центральный
   момент самопроверки. Анимация открытия — здесь приветствуется
   творчество.
4. **Раздел «Мои паттерны» отдельно от встроенных** — пользователь
   должен мгновенно отличать «это моё» от «это HSK-каталог». Сейчас
   разделение через постер-карточку наверху + отдельный экран. Можно
   переосмыслить, но граница должна остаться видимой.
5. **«Случайный sprint»** — это центральный CTA, потому что выбор
   конструкции «парализует» нового пользователя. Кнопка должна быть
   очень заметна.

## Жесты / нюансы

- Свайпом вниз закрывается модалка настроек.
- В тренажёре нет swipe-между-фразами — навигация только кнопками
  «Пропустить» / «Дальше». Это намеренно: пользователь должен
  взаимодействовать с кнопками, потому что тренируется ритм
  «вспомнил → нажал → следующая».
- Кнопка «Озвучить» в reveal-карточке играет фразу через нативный TTS
  (zh-CN, rate 0.9).
- Прогресс-бар не анимируется, просто прыгает.
- Прогресс по уровню («N / N конструкций» в карточке HSK) — сейчас
  захардкоден в 0; в будущем будем считать пройденные.

## Что сейчас «технически-минималистски» и может быть переосмыслено

Дизайнер сам решает. Список того, что **сейчас в продукте простое и
сухое** — можно сделать богаче, но это не обязательно:

- **Прогресс пользователя по конструкциям** — сейчас не показывается
  визуально. Где-то можно «огоньками» / точками показать, какие
  конструкции уже отрабатывались сколько раз и насколько быстро.
- **Уровень «горячности»** конструкции — то же самое: сейчас все
  выглядят одинаково. Можно ввести streak / heat-meter / «срок
  возврата».
- **Иллюстрации/гербы для каждой HSK-группы грамматики** — сейчас цифра
  на тёмно-бордовом. Можно сделать каллиграфические водяные знаки или
  китайские пиктограммы.
- **Reveal-карточка** сейчас — просто карточка с акцентной рамкой.
  Можно сделать «переворот», 3D-анимацию, или «бумажную карточку,
  которая поднимается из конверта».
- **Done-экран** — простая галочка. Можно дать конфетти, медальку,
  badge достижения «5 спринтов сегодня».
- **Личная колода — карточки серые и плоские**. Можно дать им свой
  визуальный язык (например, «карточки-стикеры на пробковой доске»),
  чтобы отличались от каталога.
- **Карточки конструкций в списке** — статичные. Можно ввести «дельту
  скорости» («-0.3с с прошлого раза»), «лучшее время», «сколько раз
  прогонял».
- **Модалка настроек** — функциональная, но монотонная. Можно
  сгруппировать визуально по «режиму игры» (Быстрая разминка / Глубокий
  спринт / Без давления).

Эти вещи **не обязательны** к реализации, но указывают на места, где
сейчас текстовая плотность высокая, а визуальная — низкая.

- Раздел открывается с карточки «Грамматика» на экране «Учить» (рядом
  с «Слова», «HSK каталог», «Иероглифы»).
- Палитра приложения:
  - Бумажный фон #FAFAF7, поверхность #FFFFFF, тёплая беж-поверхность
    #F5F1EA, тёплая граница #ECE7DE.
  - Красный акцент #E63946, светло-красный «muted» #FFE2E4.
  - Тоновые цвета пиньиня: #C8102E / #1F8A5B / #6A4C9C / #3D6FB5 /
    #8A847C (1/2/3/4/neutral).
  - Бордовая «постер»-палитра: #1F0C10 фон, #5A1C22 свечение,
    золотой #E0B86A для eyebrow, белый текст.
- Шрифты:
  - UI — Inter (500/600/700/800).
  - Китайский — Noto Serif SC (700/900).
  - Пиньинь — JetBrains Mono (500).
- Эстетика: «бумажный плакат + ink stamp». Большие водяные иероглифы,
  каллиграфический акцент, минимум шума, тёплые сурфейсы.

Этот раздел сейчас один из самых «нагруженных» — много чисел, уровней,
шаблонов и подписей. Главная задача дизайнера — **снизить когнитивную
нагрузку при входе** (особенно для нового пользователя, который не
понимает разницу «грамматика HSK» vs «лексика HSK»), и сделать сам
тренажёр **визуально более ритмичным**, чтобы фаза reveal ощущалась
наградой.
